# DevSecOps Demo

This repository is a lightweight example of a CI-enabled application repository intended to demonstrate practical GitHub platform usage.

## What it demonstrates
- simple application structure
- automated test execution with GitHub Actions
- repository-ready pattern for pull request validation
- foundation for adding dependency and security controls

## Why I built this
I’m interested in the intersection of customer outcomes, platform adoption, and secure software delivery. This repo is intentionally small so the workflow and operating patterns are easy to understand and extend.
